# TheLamp

Нічник на адресній стрічці WS2812B і ESP32-S3 з керуванням з телефона через Wi-Fi.

## Залізо

- ESP32-S3 N16R8 (у PlatformIO плата `4d_systems_esp32s3_gen4_r8n16`)
- стрічка 5 V на 1–300 діодів, DIN → GPIO 4 через резистор 330 Ом
- кнопка BOOT: клік — увімк/вимк, утримання — наступний ефект

Скільки діодів на стрічці, задаєш на сторінці `/setup` у картці «Стрічка» (за замовчуванням 30), перепрошивати не треба. Пін, ліміт струму й найбільша довжина стрічки — у [src/config.h](src/config.h).

## Збірка

PlatformIO → Upload. Сторінки з `web/` стискаються і вшиваються в прошивку скриптом `scripts/embed_web.py`, окремо заливати файлову систему не треба.

## Перше підключення

1. Лампа без збереженої мережі піднімає відкриту точку `TheLamp-Setup`.
2. Підключитись до неї й відкрити `http://4.3.2.1`.
3. Вибрати домашню мережу, ввести пароль.
4. Далі лампа відкривається за адресою з роутера або `http://thelamp.local`. Там же (`/setup`) можна закріпити фіксовану IP — вона скидається, коли вводиш нову мережу.

Адреса — саме `http://`, не `https://`.

## Можливості

- 16 ефектів, колір, яскравість, швидкість
- кількість діодів, що світять: з початку, по центру, з кінця або розподілено
- таймер сну з плавним згасанням
- вимикач обмеження струму
- команди через Serial (115200): `help`, `leds <кількість>`, `wifi`, `wifi forget`, `wifi ip <адреса>|dhcp`
